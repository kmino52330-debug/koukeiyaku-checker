公契約条例・賃金下限額チェッカー 業務委託版 Ver.1

【使い方】
1. index.html をChrome / Edge / Safariなどで開くと、そのまま利用できます。
2. GitHub Pagesに公開するときは、index.htmlをリポジトリのルートに置いてください。
3. ページは外部JS/CSSを使用しません。計算は端末内で行います。

【データ】
提供された「2026年度 東京都内公契約条例比較 -概要版.xlsx」から24自治体を抽出。
2026年度の参考下限額がある19自治体を表示し、残り5自治体は未収録。
自治体データはindex.html末尾のJavaScript内 DATA に埋め込まれています。
koukeiyaku_rates_2026.json は更新用に同じ情報を抽出した参考ファイルです。
JSONを変えてもindex.htmlには自動反映されません。公開用HTMLのDATAも更新してください。

【重要な制約】
条例の適用対象か、契約年度、手当の算入、業務・職種別の違いは自動判定していません。
元の比較表から採った値のため、2026年度の公式資料との全件照合前です。
正式に一般公開する前に、自治体ごとの下限額・業務範囲・年度の照合が必要です。
