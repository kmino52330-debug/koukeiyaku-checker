公契約条例 賃金チェッカー Ver.2（デモ）

【GitHub Pagesの更新】
既存リポジトリの main / root に index.html と rates.json をアップロードし、Commit changes で保存します。既存 index.html を置き換えます。旧 koukeiyaku_rates_2026.json は使用しません（削除しても構いません）。
URLは従来のままです。ローカルで index.html を直接開くとブラウザの制限でJSONを読み込めない場合があるため、GitHub PagesまたはローカルWebサーバーで確認してください。

【自治体の追加・更新】
rates.json の配列に、既存の項目をコピーして追加してください。prefecture（都道府県）、name（自治体名）、rate（時間額・数値）、year（年度・数値）を指定します。rateがnullまたは無効な場合は選択肢に出ません。同一都道府県・自治体名は有効な最新年度の行だけ表示します。年度切替の法的判定は行いません。
職種別・業務別の金額がある場合は flag を special にし、note に注意事項を記載してください。その他の契約条件は note に記載できます。
初期データは既存Ver.1の提供資料ベースの参考値を引き継いでいます。下限額と適用条件は正式公開前に確認してください。

【計算】
時給は直接比較。日給は1日の所定労働時間（初期値8時間）で割る。月給は月平均所定労働時間（初期例160時間）で割る。月額不足目安は、時給の場合は月160時間、日給の場合は月20日、月給の場合は入力した時間数で計算します。表示は参考値です。

【フォーム】
デモ表示のみ。送信、保存、外部接続はありません。正式運用時は相談窓口の合意、運営者表記の確定、個人情報の取扱い、メール送信先とバックエンド（GAS等）、迷惑送信対策の整備が必要です。
